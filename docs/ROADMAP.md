# Roadmap Denis120→80

## Как пользоваться сейчас

1. **Локально (песочница):** `npm run dev` → http://localhost:3000 — смотришь изменения сразу, без деплоя.
2. **«День»** — счётчики, вес, дневник того, что съел сегодня.
3. **«Питание»** — блок **«Мои продукты»** (повтор одной кнопкой), шаблоны, овощи, упаковка, штрих-код.
4. Еда привязана к **открытому дню** (с момента «Проснулся» до следующего «Проснулся»).

### Мои продукты

- Любой ручной ввод / OFF / штрих-код сохраняется в личную базу.
- На вкладке «Питание» сверху — список недавно использованных: меняешь граммы → **+**.
- Со штрих-кодом: следующий скан находит продукт без Open Food Facts.

### Ввод с упаковки

- На этикетке **на 100 г** → вводишь эти цифры + сколько грамм съел.
- На этикетке **на всю упаковку** (творог 300 г, 213 ккал) → блок «На упаковке только на весь продукт».
- **Два пакетика овсянки по 40 г** → либо 80 г порция с ккал/100 г с одного пакета, либо два раза по 40 г.

### Штрих-код

Open Food Facts слабо покрывает Беларусь. Если не нашёл — сохрани продукт один раз с этикетки; дальше код будет находиться в **твоей** базе (`user_products`).

**Миграции БД** (уже применены в проде):

- `supabase/migrations/20260711160000_schedule_plans.sql` — календарь смен
- `supabase/migrations/20260713120000_user_products.sql` — мои продукты
- `supabase/migrations/20260713120100_backfill_user_products.sql` — заполнение из истории дневника
