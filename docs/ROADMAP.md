# Roadmap Denis120→80

## Как пользоваться сейчас

1. **Локально (песочница):** `npm run dev` → http://localhost:3000 — смотришь изменения сразу, без деплоя.
2. **«День»** — счётчики, вес, дневник того, что съел сегодня.
3. **«Питание»** — ввод еды (шаблоны, овощи, упаковка, штрих-код).
4. Еда привязана к **открытому дню** (с момента «Проснулся» до следующего «Проснулся»).

### Ввод с упаковки

- На этикетке **на 100 г** → вводишь эти цифры + сколько грамм съел.
- На этикетке **на всю упаковку** (творог 300 г, 213 ккал) → блок «На упаковке только на весь продукт».
- **Два пакетика овсянки по 40 г** → либо 80 г порция с ккал/100 г с одного пакета, либо два раза по 40 г.

### Штрих-код

Open Food Facts слабо покрывает Беларусь. Если не нашёл — сохрани продукт один раз с этикетки; дальше код будет находиться в **твоей** базе.

**Миграции БД** (Supabase → SQL Editor):

- `supabase/migrations/20260711120000_user_barcode_products.sql` — свои штрих-коды
- `supabase/migrations/20260711160000_schedule_plans.sql` — календарь смен

## Этап 2 — ближайшие доработки

| Фича | Описание |
|------|----------|
| Календарь графика | Месяц, отметки ночных смен / выходных / отсыпных | ✅ готово |
| День по дате | Тап по дате → что ел, калории, вес | ✅ готово |
| Холодильник | Покупка по чеку → остатки продуктов дома |
| Расходы | Цены в BYN, отчёт за неделю/месяц |
| Меню из холодильника | Gemini учитывает остатки |
| Оценки блюд | Лайк/дизлайк → влияет на будущие меню |
